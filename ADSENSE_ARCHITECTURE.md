## ads.txt フロー

```
┌─────────────────────────────────────────────────────────────────┐
│              Google AdSense クローラー                             │
└─────────────────────────────────────────────────────────────────┘
        ↓
   1. サイトアクセス
   https://yourdomain.com/ads.txt
        ↓
┌─────────────────────────────────────────────────────────────────┐
│                  public/ads.txt                                  │
├─────────────────────────────────────────────────────────────────┤
│  google.com, pub-8789901212664644, DIRECT, f08c47fec0942fa0     │
│                                                                   │
│  - google.com: 広告ネットワーク識別子                              │
│  - pub-8789901212664644: Publisher ID (あなたのID)                │
│  - DIRECT: 直接契約（第三者経由ではない）                          │
│  - f08c47fec0942fa0: Google の認証ID                              │
└─────────────────────────────────────────────────────────────────┘
        ↓
   2. Publisher ID 検証
        ↓
┌─────────────────────────────────────────────────────────────────┐
│              Google AdSense サーバー                               │
├─────────────────────────────────────────────────────────────────┤
│  ✅ Publisher ID が一致                                           │
│  ✅ 広告配信を許可                                                │
│  ✅ 不正な広告インベントリを防止                                   │
└─────────────────────────────────────────────────────────────────┘
```

## コンポーネント階層

```
app/
├── layout.tsx
│   └── <AdSenseLoader />  ← 全ページで読み込み
│
└── blog/
    └── [slug]/
        └── page.tsx
            ├── <AdSenseInArticleAd adSlot="..." />  ← 記事内広告
            ├── <AdSenseDisplayAd adSlot="..." />    ← ディスプレイ広告
            └── <AdSenseRectangleAd adSlot="..." />  ← レクタングル広告
                    ↓
components/ads/
├── AdSenseLoader.tsx          ← スクリプト読み込み (全体)
├── AdSenseAds.tsx             ← プリセット広告 (簡易使用)
│   ├── AdSenseDisplayAd       ← レスポンシブディスプレイ
│   ├── AdSenseInArticleAd     ← 記事内広告
│   └── AdSenseRectangleAd     ← レクタングル広告
│           ↓
└── AdSenseUnit.tsx            ← 汎用広告ユニット (詳細カスタマイズ)
```

## データフロー図

```
[ユーザーがページ訪問]
        ↓
[Next.js SSR/SSG でHTML生成]
        ↓
[ブラウザでHTML受信]
        ↓
[AdSenseLoader が useEffect で実行]
        ↓
[AdSenseスクリプトを動的に<head>に挿入]
  <script async
          src="https://pagead2.googlesyndication.com/..."
          crossOrigin="anonymous">
        ↓
[Google AdSenseスクリプト読み込み完了]
  → window.adsbygoogle = []
        ↓
[AdSenseUnit コンポーネントがマウント]
  → <ins class="adsbygoogle" ...>
        ↓
[useEffect で (adsbygoogle).push({}) 実行]
        ↓
[Google AdSenseが広告リクエスト送信]
  → リクエスト内容:
     - Publisher ID: ca-pub-8789901212664644
     - Ad Slot: 1234567890
     - ページURL
     - ページコンテンツ (コンテキスト)
     - ユーザー情報 (Cookie/プライバシー設定)
        ↓
[Google AdSenseサーバーが広告を選択]
  - コンテキストに基づく広告
  - ユーザーの興味に基づく広告
  - 入札価格が最も高い広告
        ↓
[広告コンテンツ返却 (iframe)]
        ↓
[ブラウザで広告表示]
  <iframe src="https://googleads.g.doubleclick.net/...">
    [広告画像/テキスト/動画]
  </iframe>
        ↓
[ユーザーが広告をクリック (任意)]
        ↓
[収益発生 💰]
```

## セキュリティフロー

```
┌─────────────────────────────────────────────────────────────────┐
│                        リクエスト                                 │
└─────────────────────────────────────────────────────────────────┘
        ↓
┌─────────────────────────────────────────────────────────────────┐
│              Next.js サーバー (next.config.mjs)                   │
├─────────────────────────────────────────────────────────────────┤
│  1. CSPヘッダーを付与                                             │
│  2. X-Frame-Options: DENY                                        │
│  3. X-Content-Type-Options: nosniff                              │
│  4. Referrer-Policy: strict-origin-when-cross-origin             │
└─────────────────────────────────────────────────────────────────┘
        ↓
┌─────────────────────────────────────────────────────────────────┐
│                        ブラウザ                                   │
├─────────────────────────────────────────────────────────────────┤
│  CSPチェック:                                                     │
│  ✅ pagead2.googlesyndication.com → 許可                         │
│  ✅ googleads.g.doubleclick.net → 許可                           │
│  ❌ evil-ads.malware.com → ブロック                              │
│                                                                   │
│  XSS対策:                                                        │
│  - インラインスクリプトの制限                                      │
│  - 外部スクリプトの許可リスト                                      │
│                                                                   │
│  Clickjacking対策:                                               │
│  - X-Frame-Options でiframe埋め込みを制限                         │
│  - ただし広告iframe (許可ドメイン) は例外                         │
└─────────────────────────────────────────────────────────────────┘
        ↓
     安全な広告表示 🔒
```
