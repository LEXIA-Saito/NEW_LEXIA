## 自動広告 vs 手動広告

このプロジェクトでは**自動広告**を採用しています。

| 方式 | メリット | デメリット |
|------|---------|-----------|
| **自動広告**（採用） | 設定不要、Googleが最適配置を判断、機械学習で最適化 | 配置の細かいコントロールが難しい |
| 手動広告 | 配置を完全にコントロール可能 | スロットID取得・管理が必要、最適化は手動 |

**自動広告を活かしつつ、レイアウト設計で収益を最大化する戦略です。**

### 2.2 なぜこの配置が効果的か

| 配置位置 | 理由 | 自動広告の挙動 |
|---------|------|---------------|
| 記事上部 | ファーストビュー外で読み始め前に自然に目に入る | コンテンツ区切りを検出して挿入 |
| 記事中 | スクロール途中の休憩ポイント | H2見出し後に挿入されやすい |
| 収益ゾーン・メイン | 読了後の満足度が高い状態 | 最も広告が入りやすいスペース |
| 収益ゾーン・サブ | 次の行動を取る直前の「待ち時間」 | 関連記事との間に挿入 |

## 4. スマホでAdSense広告が確実に表示されるための構造

### 4.1 広告スペースのCSS設計

```css
/* 自動広告用プレースホルダー */
.adsense-auto-placeholder {
  display: block !important;
  width: 100%;
  min-height: 100px;  /* 広告が入るスペースを確保 */
  margin: 24px 0;
  background: transparent;
}

/* スマホ向け: より大きなスペース */
@media (max-width: 640px) {
  .adsense-auto-placeholder {
    min-height: 250px;
  }
}
```

### 4.2 やってはいけないこと

```css
/* 絶対にNG - AdSenseポリシー違反 */
.ad-container {
  display: none;        /* NG */
  visibility: hidden;   /* NG */
  opacity: 0;           /* NG */
  height: 0;            /* NG */
}
```

### 4.3 CSP（Content Security Policy）

`next.config.mjs` に以下が含まれていることを確認:

```javascript
// script-src
'https://pagead2.googlesyndication.com'
'https://adservice.google.com'

// connect-src
'https://pagead2.googlesyndication.com'

// frame-src
'https://googleads.g.doubleclick.net'
'https://tpc.googlesyndication.com'
```
